# Mocha Linux

**Hecho para jugar. Hecho para ayudar.**

Una distribución basada en Arch Linux para juegos, productividad y uso diario, con identidad propia, alto rendimiento y herramientas gráficas de actualización y recuperación.

## Qué diferencia a Mocha

- **Gran rendimiento en juegos:** diseñado para competir con Windows y otras distribuciones gamers, y capaz de superarlos en varios juegos y escenarios probados en la misma máquina.
- **Kernel Mocha LQX:** basado en Liquorix y preparado para baja latencia, respuesta rápida y rendimiento.
- **Rollback a la última configuración válida:** las actualizaciones críticas pueden revertirse cuando un kernel, controlador o componente esencial provoca un fallo.
- **Partición de recuperación dedicada:** entorno independiente para diagnóstico, reparación y restauración del sistema principal.
- **Interfaz gráfica completa:** actualización, mantenimiento, recuperación y selección de componentes sin obligar al usuario a depender de la terminal.
- **Base lista para jugar:** Steam, Proton, GameMode, MangoHud y controladores seleccionados por el proyecto.

## Rendimiento sin cifras inventadas

Mocha Linux se está comparando, en la misma máquina, con Windows y otras distribuciones orientadas a juegos. Ha obtenido ventaja en varios escenarios y se ha mantenido competitivo en los demás.

Los resultados numéricos solo se publicarán junto con el hardware, las versiones, la configuración y una metodología reproducible. El rendimiento real varía según el juego, el controlador y el equipo.

## Actualización y recuperación

Mocha está diseñado para que las actualizaciones importantes tengan una ruta clara de retorno. Cuando una actualización de kernel, controlador o componente esencial causa problemas, el sistema puede volver a la última configuración validada.

La partición de recuperación complementa este mecanismo con un entorno gráfico independiente para diagnosticar, reparar y restaurar la instalación principal.

## Causa social T21

Mocha no es solamente un proyecto técnico. Mantiene una causa social vinculada a la **Trisomía 21**, centrada en concienciación, inclusión, visibilidad, acogida y apoyo a iniciativas responsables.

Mantener el propio proyecto — infraestructura, desarrollo, pruebas, documentación y distribución — es necesario para que Mocha crezca y amplíe su impacto social de forma sostenible y transparente.

## Apoya el proyecto

El apoyo voluntario ayuda a mantener servidores, desarrollo, pruebas, empaquetado, documentación y mantenimiento. La causa social T21 se comunica con transparencia y se desarrolla según los recursos disponibles y las alianzas responsables del proyecto.

Consulta el [sitio oficial](https://dieseloslab.org/) para conocer las formas actuales de apoyo.

## Estado del proyecto

Mocha Linux está en desarrollo activo. Kernels, controladores, interfaces, herramientas y procedimientos de recuperación siguen siendo probados y documentados antes de publicar una versión estable.

## Contenido del repositorio

Este repositorio contiene la parte pública y reproducible del proyecto:

- código fuente e interfaces;
- scripts y recetas de construcción;
- configuraciones y políticas;
- documentación técnica;
- recursos visuales;
- pruebas, informes publicables y herramientas de mantenimiento.

Las cachés locales, secretos, claves privadas, imágenes completas de discos y artefactos grandes de compilación permanecen fuera de GitHub.

## Créditos

Mocha se construye sobre Linux, Arch Linux, KDE Plasma y el ecosistema de software libre, junto con proyectos como Liquorix, Steam, Proton, Wine, GameMode y MangoHud. Cada componente externo conserva su propia licencia.
