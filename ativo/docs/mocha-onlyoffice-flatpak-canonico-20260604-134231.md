# Adendo MochaArch — OnlyOffice canônico via Flatpak

Estado aprovado:
OnlyOffice Desktop Editors é canônico no Mocha via Flatpak.

App ID:
org.onlyoffice.desktopeditors

Regra:
- O OnlyOffice deve constar no perfil Mocha Gamer.
- O OnlyOffice deve constar no perfil Mocha Escritório.
- A instalação canônica é via Flathub/Flatpak, não via pacman, enquanto onlyoffice-desktopeditors não estiver disponível nos repositórios Arch ativos da instalação.
- As listas pacman não devem depender de onlyoffice-desktopeditors.
- As listas Flatpak devem registrar org.onlyoffice.desktopeditors.
- LibreOffice, Calligra e outras suítes são alternativas opcionais, não substitutas do OnlyOffice.
