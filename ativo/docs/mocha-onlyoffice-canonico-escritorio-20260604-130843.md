# Adendo MochaArch — OnlyOffice canônico no perfil Escritório

Correção aprovada:
OnlyOffice é a suíte de escritório canônica do Mocha.

Regra:
- onlyoffice-desktopeditors deve constar no perfil Mocha Gamer.
- onlyoffice-desktopeditors deve constar no perfil Mocha Escritório.
- LibreOffice, Calligra e outras suítes devem ser tratadas como alternativas opcionais.
- O perfil Escritório não substitui o OnlyOffice; ele amplia a instalação com ferramentas de produtividade, PIM, digitalização, acesso remoto e alternativas opcionais.
