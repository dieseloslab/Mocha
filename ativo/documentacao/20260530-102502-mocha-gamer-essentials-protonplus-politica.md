# Mocha Gamer Essentials - ProtonPlus como padrão

Data: 20260530-102502

Decisão: ProtonPlus passa a ser o gerenciador principal de ferramentas Proton/Wine do Mocha.

## Regras

1. ProtonPlus é o padrão principal.
2. ProtonUp-Qt continua disponível como alternativa madura.
3. A presença de ProtonUp-Qt não muda a preferência visual/operacional do Mocha.
4. AUR é permitido pacote a pacote, mas nunca em atualização geral.
5. Flatpak é aceitável quando for o método principal ou mais estável para o aplicativo.
6. vkBasalt, gamescope, LACT, CoreCtrl, Oversteer, Input Remapper, GOverlay e ferramentas similares podem estar presentes para escolha do usuário, mas não devem alterar o wrapper oficial nem as LaunchOptions canônicas sem teste específico.
7. MangoHud continua sendo componente fundamental do Mocha e deve respeitar o padrão visual Mocha.
