# MochaArch — submenu Jogos casuais / Escola

Timestamp: 20260601-111720

## Decisão

Os jogos que não são foco do perfil gamer principal devem ficar numa subpasta dentro de Jogos.

Subpasta criada no menu KDE: Jogos casuais / Escola.

Mahjong e Go permanecem fora dessa subpasta por serem exceções leves aprovadas para o perfil Gamer.

Nenhum pacote foi removido.

## Regra para a ISO

Na edição Gamer do MochaArch, manter o menu principal de Jogos limpo.

Jogos casuais que não são foco gamer entram em Jogos > Jogos casuais / Escola.

Mahjong/Go podem permanecer no nível principal de Jogos se estiverem instalados.
