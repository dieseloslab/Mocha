# Mocha

**Site oficial:** https://dieseloslab.org

Mocha é uma distribuição/receita de sistema Linux criada para oferecer uma experiência pronta, elegante, reproduzível e bem ajustada para diferentes tipos de uso real.

O projeto nasceu como um laboratório de sistema operacional com foco em desempenho, estabilidade, personalização visual, documentação clara e reprodutibilidade. A meta é permitir que uma máquina seja montada novamente do zero com a mesma identidade, os mesmos ajustes e a mesma base técnica validada.

## Objetivo social

O Mocha também tem uma causa.

Além de ser um projeto técnico, o Mocha nasce com uma proposta social: transformar tecnologia, documentação, testes e distribuição em uma iniciativa capaz de gerar impacto real.

As arrecadações, doações, apoios e eventuais receitas ligadas ao projeto serão direcionados para:

- manter e desenvolver o próprio projeto Mocha;
- financiar infraestrutura, testes, documentação, empacotamento e distribuição;
- apoiar a causa T21, ligada à inclusão, visibilidade e suporte às pessoas com Trissomia do 21 / Síndrome de Down.

A ideia é que o Mocha não seja apenas uma distribuição de sistema, mas também uma ponte entre tecnologia livre, acessibilidade, inclusão e impacto social.

## Versões e públicos

### Mocha Gamer

Versão voltada para jogos, com foco em desempenho, baixa latência, Steam, Proton, ferramentas de jogos, telemetria opcional de diagnóstico, kernel e drivers validados.

### Mocha Creator

Versão voltada para criadores de conteúdo, com foco em estabilidade, produtividade, ferramentas de criação, boa experiência visual e base reproduzível para fluxos de imagem, vídeo, áudio e trabalho criativo.

### Mocha Escolas

Versão voltada para máquinas de escolas, laboratórios e salas de aula, com foco em instalação padronizada, manutenção simplificada, interface amigável, consistência entre várias máquinas e reaproveitamento de hardware quando possível.

### Mocha Escritórios

Versão voltada para escritórios, atendimento, recepção e uso administrativo, com foco em produtividade, estabilidade, visual limpo, ferramentas essenciais e manutenção previsível.

## Reprodutibilidade

Um dos princípios centrais do Mocha é a reprodutibilidade.

O sistema deve poder ser remontado a partir de uma base canônica, com arquivos, receitas, documentação, scripts, políticas, assets e registros necessários para reproduzir o estado validado da máquina.

O objetivo é reduzir improvisos, evitar perda de conhecimento técnico e permitir que ajustes aprovados sejam documentados, testados, reaplicados e evoluídos de forma organizada.

## Observação sobre este repositório

A pasta canônica local do projeto pode conter caches, resultados de build, artefatos binários, cópias de estado do sistema e arquivos grandes demais para GitHub.

Por isso, este repositório público recebe a parte publicável e segura do Mocha:

- documentação;
- receitas;
- módulos;
- scripts;
- manifestos;
- políticas;
- assets visuais pequenos e médios;
- arquivos necessários para entender, testar e reproduzir o projeto.

Caches offline completos, arquivos binários grandes, cópias locais de sistema, resultados de build, segredos, chaves privadas, certificados e arquivos locais sensíveis ficam fora do GitHub.

## Créditos

O Mocha é construído sobre o trabalho de várias comunidades e projetos de software livre, incluindo:

- Linux;
- Arch Linux;
- KDE Plasma;
- Mesa;
- NVIDIA Linux;
- Steam, Proton, Wine e o ecossistema Linux gaming;
- projetos livres usados na construção, diagnóstico, empacotamento, documentação e personalização do sistema.

O Mocha existe porque esse ecossistema existe.

## Estado do projeto

O Mocha ainda é um projeto em desenvolvimento ativo.

As receitas, kernels, temas, módulos, scripts, políticas, validações e ferramentas podem mudar conforme novos testes forem feitos.

O objetivo é transformar as partes aprovadas em documentação canônica, com histórico claro do que funciona, do que foi descartado e do que ainda precisa ser validado.
