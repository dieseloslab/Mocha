A EXPERIÊNCIA MOCHA

Base segura na instalação. Desempenho ajustado ao hardware.

A ISO é planejada com kernel Arch LTS genérico. Depois da instalação, o MochaArch detecta CPU e GPU e pode sugerir, com consentimento do usuário, uma pilha validada de kernel, headers e driver para melhor desempenho.

  • Kernel Arch LTS mantido como fallback seguro.
  • Detecção posterior de arquitetura da CPU e GPU.
  • Upgrade voluntário pelo repositório Mocha controlado.
  • Sem habilitar o repositório CachyOS no computador do usuário.
