# Pós-instalação Mocha - roteiro inicial

Itens que devem virar scripts idempotentes:
- habilitar sddm.service
- configurar SDDM Wayland com Breeze e fundo Mocha
- habilitar NetworkManager
- habilitar ufw com entrada negada e saída liberada
- configurar systemd-resolved com DNS-over-TLS
- instalar/aplicar wrapper Steam canônico
- instalar/aplicar MangoHud Mocha
- aplicar tema, wallpaper e painel Mocha
- aplicar TuneD/performance quando validado
- remover pacotes não gamer do perfil Mocha Gamer
- não configurar rclone pessoal na ISO pública
