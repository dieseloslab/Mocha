# English base / fallback

## Welcome

Welcome to Mocha.

Mocha is an Arch-based KDE Plasma system built for gaming, daily use and careful performance tuning. This installer will prepare a clean Plasma desktop with the Mocha defaults, SDDM, Wayland, gaming tools and a practical base for Steam, Proton and modern Linux gaming.

Mocha is also a personal and social project. Its goal is to deliver a polished system that can help support a wider cause through visibility, donations and community interest.

## Slide 1 — Gaming-first Arch base

Mocha starts from Arch and focuses on a gaming-ready desktop. The system is designed around KDE Plasma, current graphics stacks, Steam/Proton workflows, GameMode, MangoHud and practical performance settings.

## Slide 2 — KDE Plasma only

This first Mocha release installs KDE Plasma as the only graphical desktop. The goal is consistency: one interface, one display manager, one visual identity and fewer conflicting desktop components.

## Slide 3 — Wayland and SDDM

Mocha uses SDDM and a Wayland-first Plasma session. The installation keeps the graphical stack focused on the tested Mocha path instead of mixing unrelated sessions.

## Slide 4 — Practical tools

The system is prepared for gaming, browsing, office work, media tools and daily maintenance. The default selection favors useful applications without turning the installation into a cluttered desktop.

## Slide 5 — Social purpose

Mocha is built with a social purpose. The project aims to create a system that is useful, attractive and capable of drawing support for a meaningful cause.

## Finished

Installation is complete. Restart the computer, remove the installation media and boot into Mocha.

# Português inicial

## Boas-vindas

Bem-vindo ao Mocha.

O Mocha é um sistema baseado em Arch com KDE Plasma, criado para jogos, uso diário e ajustes cuidadosos de desempenho. Este instalador preparará um desktop Plasma limpo com os padrões Mocha, SDDM, Wayland, ferramentas gamer e uma base prática para Steam, Proton e jogos modernos no Linux.

O Mocha também é um projeto pessoal e social. Seu objetivo é entregar um sistema bem acabado que possa ajudar uma causa maior por meio de visibilidade, doações e interesse da comunidade.

## Slide 1 — Base Arch com foco gamer

O Mocha parte do Arch e foca em um desktop pronto para jogos. O sistema é pensado em torno do KDE Plasma, pilhas gráficas atuais, fluxos Steam/Proton, GameMode, MangoHud e ajustes práticos de desempenho.

## Slide 2 — Somente KDE Plasma

Esta primeira versão do Mocha instala o KDE Plasma como única interface gráfica. O objetivo é consistência: uma interface, um gerenciador de login, uma identidade visual e menos componentes conflitantes.

## Slide 3 — Wayland e SDDM

O Mocha usa SDDM e uma sessão Plasma com prioridade para Wayland. A instalação mantém a pilha gráfica focada no caminho testado do Mocha, sem misturar sessões sem relação com o projeto.

## Slide 4 — Ferramentas práticas

O sistema é preparado para jogos, navegação, escritório, mídia e manutenção diária. A seleção padrão prioriza aplicativos úteis sem transformar a instalação em um desktop poluído.

## Slide 5 — Propósito social

O Mocha é construído com um propósito social. O projeto busca criar um sistema útil, atraente e capaz de atrair apoio para uma causa significativa.

## Finalização

A instalação foi concluída. Reinicie o computador, remova a mídia de instalação e inicie o Mocha.
