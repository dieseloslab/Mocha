# Análise visual do Calamares Mocha

Este diretório contém a análise visual canônica dos recursos encontrados no Calamares usado como base técnica.

## Conteúdo versionado

- `canonica/`: conjunto visual selecionado como referência.
- `documentacao/classificacao-final/`: comparação das versões analisadas.
- `documentacao/comparacao-integral.tsv`: classificação estrutural por hash.

## Resultado da auditoria

- A versão canônica possui 16 imagens originais, 16 miniaturas e 2 pranchas.
- As duas versões anteriores não apresentam diferenças nas imagens.
- Cada versão anterior difere da canônica somente em um arquivo textual.
- Os lotes timestampados permanecem apenas como material local de trabalho.

## Próxima utilização

A análise serve como referência para substituir imagens, branding, textos e slideshow provisórios pela identidade própria do Mocha.
